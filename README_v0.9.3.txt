Ashen Builds v0.9.3 - Talent Rendering Hotfix

Fixes the talent data registry used by the generated Turtle WoW class files.
The class files populate TalentedTooltipData; Ashen Builds now shares that exact
table through AshenBuildsTalentData, allowing all talent icons, ranks, names,
descriptions, prerequisites, and stat effects to render.

Install by deleting the previous AshenBuilds folder and copying this folder into
Interface\AddOns. Fully restart Turtle WoW.
